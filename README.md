# WERITI1

Краткое описание проекта. Например: "Веб-приложение для воспроизведения звуков и работы с базой данных".

## 🚀 Технологии
* **Frontend:** HTML, CSS, JavaScript
* **Backend/Database:** SQL (SQLite/MySQL/PostgreSQL - *выберите нужное*)

## 📂 Структура проекта
* `index.html` - Основная HTML-страница (интерфейс пользователя).
* `style.css` - Стили и визуальное оформление.
* `app.js` - Основная логика приложения.
* `sound.js` - Скрипты, отвечающие за работу со звуком.
* `schema.sql` - Схема базы данных (таблицы, связи).
